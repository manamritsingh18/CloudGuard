SYSTEM BOUNDARIES

Understand the deployment.

Does it automatically restart a stopped container?+

A deliberate Docker stop remains stopped until an operator starts it. The unless-stopped policy restarts a container after an unexpected process exit. Detection, routing around a failure, and restart are separate mechanisms.

Is the availability value a production SLA?+

No. It is the percentage of successful recorded probes in the selected observation window. Gaps while monitoring is off are unobserved, and a few successful minutes do not establish long-term uptime.

Can this be accessed from another computer?+

The default setup is bound to localhost on the host computer. Share the screen or run the project locally on another computer. It does not publish a public site or expose the host to network visitors.

What does the architecture provide?+

Operating-system-level isolation through containers, horizontal replication, service networking, reverse proxy load balancing, persistent storage, health monitoring, fault tolerance, and sample-based service measurements.
